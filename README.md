3Haib Privacy Policy

Last updated: July 27, 2026

3Haib (“we”, “our”) provides an anonymous photo rating app.

Information we collect
• Device identifier used as a rater ID (no login account)
• Ratings you submit
• If you request to join: name, country, gender, and photos
• Basic app preferences (language, theme)

How we use information
• To show and rate people in the app
• To run the Fire leaderboard
• To process add/remove requests
• To operate and improve the app

Sharing
We do not sell your personal information. Data is stored on our service providers (such as Supabase) to run the app.

Data retention
We keep information as long as needed to operate the app and process requests. You may request removal through the app’s remove request flow or by contacting us.

Children
3Haib is not directed to children under 13.
